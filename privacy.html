Política de privacidade

Investimentos CDI é uma automação de uso pessoal. Esta descrição abrange o acesso ao Google Drive e o processamento dos relatórios no GitHub Actions.

Acesso e finalidade

O escopo solicitado é https://www.googleapis.com/auth/drive.file. Ele permite trabalhar com arquivos criados pelo aplicativo ou explicitamente autorizados para uso com ele. A finalidade é guardar relatórios, consultar a edição anterior e registrar entradas e saídas das listas de ativos. A integração não solicita acesso geral a outros arquivos do Drive.

Processamento e armazenamento

O GitHub Actions processa os arquivos necessários em servidores hospedados pelo GitHub. As credenciais de autorização ficam nos secrets criptografados do repositório privado, separadas do código. Relatórios de validação e resultados podem ficar nos artefatos privados do repositório pelo prazo de retenção configurado. O histórico de relatórios permanece no Drive do proprietário até sua exclusão por ele.

Compartilhamento

Os arquivos de trabalho não são publicados nesta página. O uso dos serviços Google Drive e GitHub Actions implica processamento por esses provedores para executar a automação. Os dados não são vendidos nem utilizados para publicidade. A finalidade do acesso às APIs Google é limitada ao funcionamento descrito nesta política, em conformidade com a Política de Dados do Usuário dos Serviços de API do Google, inclusive seus requisitos de uso limitado.

Controle do proprietário

O proprietário pode revogar o acesso na seção de conexões da sua Conta Google, excluir os secrets do repositório e apagar os arquivos do Drive e os artefatos do GitHub. Revogar o acesso impede as próximas operações da automação; não apaga automaticamente os arquivos já existentes.
